SnapTrack

AI · Flask · Gemini

An AI nutrition tracker: take a photo of a meal, and Gemini analyzes it to estimate calories and macros, which get logged automatically. Built with Flask and the Gemini API, with a Postgres (Neon) backend in production and a vanilla JS front end.

I ran an accuracy evaluation against 50 real dishes from the Nutrition5k dataset and used the results to fix a systematic bias in the model's prompting — cutting calorie error (MAPE) from 35.6% to 33.4% and fat error from 177% to 47%. Funded as 1 of 20 teams building for open-source smart glasses (Mentra).

Antralio Redact

Tauri · Rust · Python

A desktop app that redacts personal information (names, IDs, addresses) from Portuguese rental contracts before they're shared or filed. Built with Tauri (Rust shell) and a Python sidecar using Presidio, spaCy, and PyMuPDF to detect and black out sensitive text in PDFs.

Shipped to a real client through a private Microsoft Store listing — a workaround for the client's endpoint-protection policy, which blocked unsigned executables on their Windows Cloud PCs. The client updates automatically through the Store.

TributeFlow

Python · GitHub Actions · Automation

An automation pipeline for a nonprofit (Charlottesville-Albemarle SPCA) that replaces a manual CSV-export-and-git-push workflow with one click. Staff select "Publish to Wall" in a Google Sheet, which triggers a GitHub Action that validates the data, deduplicates entries, and publishes an updated tribute wall.

The client declined to use AI for this step, so I built a deterministic dedup engine instead (exact-match on honoree + donor name) with an eval harness (precision/recall/F1 against 18 labeled cases) to validate it — plus an optional agent-based mode behind the same interface for future use. 44+ tests, CI on every change.
