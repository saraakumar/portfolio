# Portfolio

Personal portfolio site. Plain HTML/CSS, no build step — deployable as-is to GitHub Pages, Netlify, or Vercel.

## Local preview

```
open index.html
```

or serve it:

```
python3 -m http.server 8000
```

## Deploy (GitHub Pages)

1. Push this repo to GitHub.
2. In repo Settings → Pages, set source to the `main` branch, root folder.
3. Site publishes at `https://<username>.github.io/<repo>/`.
